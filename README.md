# Hey, I'm Ali.

I like writing software and figuring out what happens underneath it. Most of my time goes into backend development, software architecture and systems programming, though I tend to wander into other areas whenever something catches my interest.

C# and .NET are where I feel most at home. I also work with C, JavaScript/TypeScript, Python and Rust. I like collecting tools more than I like pledging allegiance to any particular one.

## What I get up to

- Building APIs and experimenting with different ways of structuring them.
- Working with embedded systems, and low-level stuff.
- Occasionally venturing into ui dev when something needs a face.
- Working toward an M.Sc. in Computer Science and Engineering (Software).

## Things I write

I wrote [**Quick Rust**](https://quickrust.site), or, by its considerably less concise title, *A Quick Guide for Everything Rust When You're Too Lazy to Relearn It.*

It started as a collection of notes for my future self and somehow turned into a book. If you've already learned Rust and need to remember how something works without rereading an entire textbook, you might find it useful.
